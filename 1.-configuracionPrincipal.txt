1.- [crear un entorno]

    -> python -m venv venv

2.- [activar variables de entorno]
    -> source /venv/bin/activate

3.- [Instalar dependencias]

    -> fastapi uvicorn  

4.- [levantar servidor]

    -> uvicorn main:app
    -> uvicorn main:app --port 8000 --reload
    -> uvicorn main:app --host 0.0.0.0 --port 8000 --reload

5.- [Crear Estructura de Proyecto]

    fastapi
      |
      |
      |--app
      | |--api
      | |--core
      | |--crud
      | |--db
      | |--models
      | |--schemas
      | |-- main.py 
      |--venv
      |--.env
      |--.requeriments.txt
