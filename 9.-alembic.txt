1.- Instalar el paquete alembic:
 -> pip install alembic

2.- Crea o inicializar alembic
 -> alembic init -t async alembic

3.- Configurar alembic.ini y agregar la ruta de conexion a la bd
  -> sqlalchemy.url = postgresql+asyncpg://admin:password@localhost:5432/mydb

4.- Entar el la carpeta alembic y editar el archivo env.py y agregar la siguiente lineas
   -> from models.models import SQLModel
   -> Agregar: target_metadata = SQLModel.metadata

5.- [Realizar Migraciones]
    Navegar dentro de la carpeta app
  
  -> alembic upgrade head
  -> Si ocurre error agregar en el archivo de versiones que se genera
     -> import sqlmodel

6.- Commit de alembic
  -> alembic revision --autoupgrade -m  "Create initial, user, product, category, review"
